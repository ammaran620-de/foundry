## Model weights in the repository

`browser/public/models/yolo26n_webgpu.onnx` is an ONNX export of the Ultralytics YOLO26n COCO checkpoint. Ultralytics publishes its code and pretrained weights under AGPL-3.0 (the `ultralytics` package on PyPI declares AGPL-3.0; checked 2026-11-17), with a separate paid enterprise licence as the alternative. Treat the exported file as a derivative of those weights under AGPL-3.0, not as MIT.

## Evaluation data

`benchmark/evaluation/` holds manifests and `data.yaml` files that list a 1,000-image and a 300-image subset of COCO. The images are not in the repository. COCO annotations are published under CC BY 4.0 and the images under their Flickr terms; I could not re-check that wording from this environment, so confirm it on cocodataset.org before redistributing any of the images.

`benchmark/input/benchmark_640.png` is generated by `benchmark/create_input.py` from a fixed random seed and is original to this repository.

## Open question

I have not settled whether MIT code that imports the AGPL-3.0 `ultralytics` package, and is published beside an AGPL-derived model file, can stay MIT as a whole when someone redistributes it. This is a legal question, not a technical one. The options are to keep the current arrangement with this notice, to relicense the repository as AGPL-3.0, or to drop the bundled ONNX file and the `ultralytics` dependency. Nothing has been changed pending that decision, and the code and weights are not offered as cleared for commercial redistribution.

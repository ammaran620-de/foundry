# M3 Failure Gallery

Real failures observed during the RunsOnAnything browser demonstration.

## Test Context

Model: YOLO26n
Runtime: WebGPU
Input: 640 × 640
Source: recorded browser demonstration

## Failure Record

Each failure should contain:

- Failure ID
- Timestamp
- Input condition
- Expected
- Observed
- Diagnosis
- Severity
- Evidence

## Rule

Do not count the same failure repeatedly unless the failure condition is materially different.
